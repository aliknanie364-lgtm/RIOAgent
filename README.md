# RIOAgent 2.1.0

Android application for screen capture, red-marker radar, decision preview, touch recording within the app, and a draggable floating status panel.

See [README-AR-2.1.md](README-AR-2.1.md) for Arabic setup instructions and technical limitations.

Important: automatic game control is not calibrated by default. The decision engine reports suggested steering only; do not enable automation until on-device control coordinates have been measured and tested.
