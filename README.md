# RIOAgent

تطبيق Android مساعد للعبة RIO RISE. هذه النسخة توفر:
- واجهة عربية لتشغيل وإيقاف جلسة المساعدة.
- التقاط شاشة الجهاز بعد موافقة المستخدم عبر Android MediaProjection.
- تحليل بصري أولي للإطار (متوسط السطوع ونسبة الألوان الدافئة/الباردة) دون حفظ صور الشاشة.
- إشعار دائم أثناء جلسة الالتقاط.
- بناء APK تلقائياً عبر GitHub Actions.

## ما الذي لا تدّعيه هذه النسخة؟
لا تحتوي النسخة الحالية على نموذج مدرّب للتعرف على عناصر RIO RISE أو استراتيجية لعب مؤكدة، ولا تنفذ لمساً آلياً أو تتجاوز حماية اللعبة. التحليل الحالي عام، ويحتاج قواعد/نموذجاً مخصصاً بعد توفير لقطات واضحة من اللعبة واختبارها.

## البناء
يتطلب Android Gradle Plugin 8.7.3 وGradle 8.9 وJDK 17.
يمكن البناء محلياً باستخدام:
`gradle assembleDebug`
وسيكون الملف الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

عند رفع المشروع إلى GitHub، ينفذ Workflow البناء تلقائياً ويمكن تنزيل APK من Artifacts.

## الخصوصية
التقاط الشاشة لا يبدأ إلا بعد موافقة صريحة من نافذة Android. الإطارات تعالج في ذاكرة التطبيق ولا تحفظ كصور. أوقف الجلسة من زر الإيقاف أو من إشعار التطبيق.
