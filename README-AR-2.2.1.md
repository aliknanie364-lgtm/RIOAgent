# RIO Agent 2.2.1 — التحكم المستمر

هذا تحديث على 2.2.0 يعالج فجوة التحكم: أصبحت عصا الحركة تُدار كسلسلة إيماءات Accessibility مستمرة باستخدام `StrokeDescription.continueStroke` بدلاً من سحبات منفصلة ترفع الإصبع بينها.

- تحديث موضع العصا باستمرار وفق قرارات الرادار.
- دمج نقرات الضرب والركض داخل سلسلة الإيماءة نفسها حتى لا تلغي إيماءة منفصلة لمسة الحركة.
- وضع حد زمني للضرب والركض لتقليل النقرات المتكررة.
- إنهاء لمسة الحركة عند إيقاف الأتمتة أو توقف خدمة الالتقاط.

يتطلب هذا المسار Android API 26 أو أحدث (والحد الأدنى للمشروع 26). لم يتم بناء APK في بيئة العمل الحالية لعدم توفر Android SDK/Gradle، ولم يُختبر على جهاز فعلي. ما زال التعرف محدوداً بأشرطة الصحة الحمراء؛ لا يوجد حتى الآن تجنب موثوق للعوائق أو قفز تلقائي.
