# RIO Agent 2.2.2 — تحسين الاستقرار

- يحافظ متحكم اللمس على إصبع عصا الحركة عبر `StrokeDescription.continueStroke` ويحدّث اتجاهه دون رفع الإصبع بين المقاطع.
- يرسل الضرب والركض كلمسات إضافية ضمن الإيماءة نفسها.
- يعالج رفض Handler لاستقبال إطار أثناء إيقاف الالتقاط، ويحرر Bitmap ويعيد قفل التحليل لتجنب توقفه الدائم.
- الإصدار: 2.2.2 (versionCode 17).

حدود معروفة: يلزم بناء Android فعلي وتجربة على الجهاز للتحقق من قبول اللعبة للإيماءات المتزامنة. كشف الهدف يعتمد على أشرطة الصحة الحمراء فقط؛ لا يوجد بعد تجنب عوائق موثوق أو قفز تلقائي.
