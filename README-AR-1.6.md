# RIOAgent 1.6 — مسجل الحركات (نسخة تجريبية)

## ما أضيف
- إضافة واجهة تسجيل وإيقاف/حفظ وتشغيل آخر تسجيل.
- تسجيل مسارات مؤشرات اللمس وتوقيتها مع حفظ إحداثيات نسبية لتناسب اختلاف دقة الشاشة.
- دعم عدة مؤشرات لمس متزامنة ضمن حدود GestureDescription.
- حفظ التسجيلات محلياً داخل مساحة التطبيق الخاصة.
- الإبقاء على خدمة التقاط الشاشة والتحكم الموجودة بالمشروع.

## متطلبات وحدود مهمة
- ميزة استقبال MotionEvent من AccessibilityService تتطلب Android 14 (API 34) أو أحدث.
- يعتمد استقبال أحداث اللمس على دعم النظام لوضع إرسال أحداث الحركة لخدمة إمكانية الوصول. وثائق Android تربط إرسال أحداث اللمس بوضع استكشاف اللمس (Touch Exploration)؛ قد لا تصل الأحداث في كل الأجهزة/الألعاب أو في الوضع العادي. لا تفعّل Touch Exploration إلا إذا كنت تعرف أثره على طريقة اللمس لديك.
- هذه النسخة لا تنشئ طبقة شفافة تعترض اللمس ثم تمرره؛ لذلك لا أدعي أن التقاط جميع الحركات مضمون على كل جهاز.
- إعادة التشغيل تستخدم AccessibilityService.dispatchGesture؛ قد تلغي إيماءات جارية، وقد ترفض اللعبة بعض الإيماءات أو تتعامل معها بشكل مختلف.
- لا يوجد اختبار بناء أو اختبار جهاز فعلي ضمن بيئة إعداد هذه الحزمة. يجب أن ينجح GitHub Actions أولاً ثم تختبر التسجيل في لعبة فعلية قبل الاعتماد عليها.

## البناء
ارفع محتويات الحزمة إلى فرع main ثم افتح GitHub Actions ونزّل artifact باسم RIOAgent-1.6-debug-APK.
