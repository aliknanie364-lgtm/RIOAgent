# RIOAgent 1.4 — تحديث التحكم

هذه حزمة تحديث فوق مشروع RIOAgent الحالي، وليست مشروعاً مستقلاً.

## ما الذي تغير؟
- منع تداخل إيماءات اللمس: خدمة إمكانية الوصول تنفذ اللمسات والسحب بالتتابع بدلاً من إرسال إيماءة جديدة أثناء تنفيذ السابقة.
- السماح باستمرار الماكرو عند الانتقال من واجهة RIOAgent إلى اللعبة (كان onStop يوقفه فوراً).
- حفظ إحداثيات الأزرار تلقائياً واستعادتها عند فتح التطبيق.
- تعديل نقطة عصا الحركة الافتراضية تقريبياً إلى 25%,72% بناءً على لقطة اللعبة التي أرسلها المستخدم. يجب معايرتها على الجهاز.
- رفع الإصدار إلى 1.4.0 وتسمية Artifact الجديدة.

## تطبيق التحديث عبر Termux
1. ضع ملف ZIP في مجلد Download.
2. نفّذ الأمر التالي (إذا كان مجلد المشروع المحلي اسمه RIOAgent-New):

```bash
cd /storage/emulated/0/Download && unzip -o RIOAgent-1.4-Upgrade.zip -d RIOAgent-New && cd RIOAgent-New && git add . && git -c user.name="RIOAgent" -c user.email="rioagent@example.com" commit -m "Upgrade RIOAgent to 1.4 stable gesture queue" && git push origin main
```

3. افتح GitHub > Actions وانتظر نجاح Build RIOAgent APK.
4. نزّل Artifact باسم `RIOAgent-1.4-debug-APK`.

## حدود معروفة يجب عدم إخفائها
- لا يمكن اختبار اللمس الفعلي أو أداء اللعبة من بيئة البناء؛ اختبره داخل اللعبة أولاً.
- هذا الإصدار ما زال يستخدم ماكرو ثابتاً (تحريك ثم ضرب ثم قفز)، وليس نظاماً يفهم حالة اللعبة. إحداثيات الأزرار تختلف بين الأجهزة وتخطيطات اللعبة.
- استمرار الماكرو يعتمد على بقاء عملية Android حية؛ قد يوقفه النظام إذا قتل التطبيق في الخلفية.
- لم نغيّر صلاحيات Android أو نطلب صلاحيات إضافية.
